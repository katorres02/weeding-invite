SECTION 5: ANIMATION SPECIFICATIONS
================================================================================

-- WAX SEAL (idle, before click) --
  CSS keyframe: sealPulse
  Behavior: scale 1→1.06→1, drop-shadow pulse (burgundy glow)
  Duration: 2.5s, ease-in-out, infinite
  CSS property: transform-box: fill-box (required for SVG elements)

-- ENVELOPE OPEN (GSAP timeline, triggered on #wax-seal click) --
  Prerequisites:
    gsap.set('#envelope-flap', { svgOrigin: "200 0" })  // set before timeline
    gsap.set('#envelope-back', { svgOrigin: "200 140" }) // center of envelope

  Timeline steps:
    t=0.0s: Disable #wax-seal pointer-events, add class 'clicked' (stops pulse animation)
    t=0.0–0.4s: Tween #wax-seal: scale→0, opacity→0, ease:"power2.in"
    t=0.2–0.8s: Tween #envelope-flap: rotateX→-180deg, ease:"power2.inOut"
                NOTE: rotateX negative = opens toward viewer
    t=0.6–1.2s: Tween #letter-card: y 40→-60 (relative), opacity 0→1, ease:"power1.out"
    t=1.0–1.8s: Tween #envelope-screen: opacity→0, ease:"power2.inOut"
                onComplete:
                  document.getElementById('envelope-screen').classList.add('hidden')
                  const inv = document.getElementById('invitation')
                  inv.style.opacity = '1'
                  inv.style.pointerEvents = 'auto'
                  // trigger hero animations
                  document.querySelectorAll('.hero-animate').forEach(el => el.style.animationPlayState = 'running')
                  AOS.refresh()

  REDUCED MOTION: Check prefers-reduced-motion. If true, skip GSAP and show invitation immediately.
  Implementation: if (window.matchMedia('(prefers-reduced-motion: reduce)').matches) { skipEnvelope() }

-- HERO ENTRANCE (after envelope fade) --
  CSS keyframe: heroReveal
  From: opacity:0, translateY(24px), letter-spacing wider
  To:   opacity:1, translateY(0), letter-spacing normal
  Duration: 1.2s, cubic-bezier(0.16, 1, 0.3, 1)
  Applied via .hero-animate class, with .delay-1 and .delay-2 variants

-- SCROLL ANIMATIONS (AOS) --
  Init: AOS.init({ duration: 900, once: true, offset: 80, easing: 'ease-out-cubic' })
  All sections use: data-aos="fade-up"
  Cards use staggered delay: data-aos-delay="100", "200", "300"

-- COUNTDOWN DIGIT CHANGE --
  CSS keyframe: digitFlip
  From: translateY(-20%), opacity:0
  To:   translateY(0), opacity:1
  Duration: 0.3s ease-out
  Triggered: JS adds .cd-flip class on each unit when value changes, removes after 350ms

-- GALLERY HOVER --
  CSS: figure:hover img { transform: scale(1.04) }
  Transition: 0.6s cubic-bezier(0.16, 1, 0.3, 1)
  Overflow: hidden on figure

-- LIGHTBOX --
  Show: #lightbox[hidden] removed, keyframe lightboxIn (scale 0.92→1, opacity 0→1, 0.35s)
  Hide: add [hidden] attribute
  Close triggers: #lb-close click, Escape key, click outside image
  Navigation: #lb-prev / #lb-next, ArrowLeft / ArrowRight keys
  Focus: trap focus inside lightbox when open

REQUIRED BEFORE LAUNCH (replace these strings in index.html):

  COUPLE_NAME_1          → Full name of partner 1
  COUPLE_NAME_2          → Full name of partner 2
  WEDDING_DATE_DISPLAY   → e.g. "Sábado, 14 de Febrero de 2026"
  WEDDING_DATE_ISO       → e.g. "2026-02-14T17:00:00" (used in countdown.js)
  WEDDING_TIME           → e.g. "17:00 hrs"
  VENUE_NAME             → Name of wedding venue
  VENUE_ADDRESS          → Full address string
  VENUE_MAPS_EMBED_URL   → Google Maps embed URL (see instructions below)
  GOOGLE_FORM_URL        → RSVP Google Form URL (see instructions below)
  GIFT_REGISTRY_URL      → Link to gift registry (Amazon, Liverpool, etc.)
  DRESS_CODE_LABEL       → e.g. "Formal" / "Cocktail" / "Etiqueta Rigurosa"
  DRESS_CODE_DESCRIPTION → Guidance paragraph (2-3 sentences)
  STORY_TEXT             → "Our story" paragraph (3-5 sentences)
  RSVP_DEADLINE          → e.g. "Confirma antes del 1 de Febrero de 2026"
  WAX_SEAL_MONOGRAM      → 1-2 initials for the wax seal SVG (e.g. "CT")

PHOTO FILES (place in /assets/images/):
  photo-1.jpg  → main couple photo (spans 2 grid columns)
  photo-2.jpg  → couple photo 2
  photo-3.jpg  → couple photo 3
  photo-4.jpg  → couple photo 4
  photo-5.jpg  → couple photo 5
  Recommended: 1200x800px minimum, JPG format, <500KB each

GOOGLE MAPS EMBED URL (how to get it):
  1. Go to maps.google.com
  2. Search for venue address
  3. Click Share → Embed a map → Copy HTML
  4. Extract the src="..." URL from the iframe tag
  5. Paste as VENUE_MAPS_EMBED_URL

GOOGLE FORM RSVP SETUP (how to get URL):
  1. Go to forms.google.com, create new form
  2. Suggested fields: Nombre completo, Número de asistentes, ¿Asistirás? (Sí/No), Restricciones alimentarias, Mensaje para los novios
  3. Connect to Google Sheets: Responses tab → Link to Sheets
  4. Click Send button in Forms → Link icon → Copy URL
  5. Paste as GOOGLE_FORM_URL in index.html

JS: maintain currentIndex, images array from .gallery-grid figure[data-full] attributes

-- COUNTDOWN TIMER --
Target element: #countdown
  Child divs: .countdown-unit each containing:
    span#cd-days / #cd-hours / #cd-minutes / #cd-seconds
    label text
Logic in js/countdown.js:
  const WEDDING_DATE = new Date('WEDDING_DATE_ISO')
  setInterval updates every 1000ms
  On digit change: add .cd-flip to span, setTimeout remove after 350ms
  Edge case: if countdown <= 0, display "¡Hoy es el gran día!" and clearInterval
